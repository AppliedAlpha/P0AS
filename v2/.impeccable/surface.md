# 출석과 운영 화면

Mode: Operate. 학생은 현장에서 휴대폰으로 입력하고, 운영자는 노트북에서 명단과 예외를 처리한다. 사용자는 전체 구현, 차분하고 빠르게 읽는 화면, 코드 우선 작업을 확인했다.

## Direction contract

THESIS: 대학 도서관 무인 대출기의 확인 흐름을 가져온다. 입력 영역은 명확하고 완료 화면은 기록 한 장처럼 단정하게 끝난다. 학생에게는 한 번에 한 작업을 제시한다.

OWN-WORLD: 밝은 회백색 배경, 짙은 녹색 주요 동작, 얇은 회녹색 구분선. 한글 산세리프, 고정 크기, 큰 입력칸과 절제된 라운드. 상태는 문구와 아이콘을 함께 사용한다.

STORY: 현장 토큰을 준비하고 본인 정보를 입력하고 출석을 마친다. 결과 조회는 별도 경로로 즉시 접근한다. 관리자에게는 명단 중심 작업 공간을 제공한다.

FIRST VIEWPORT: 모든 폭의 학생 화면은 최대 440px의 한 열로 제한한다. 브랜드와 행사명, 출석/조회 탭, 입력 폼, 접을 수 있는 개인정보 안내와 필수 동의 체크, 실행 버튼만 둔다. 환경 표시·학기·상태 배지·푸터·마케팅 문구는 제거한다. 관리자 화면은 세로 내비게이션, 중앙 명단, 보조 활동 기록을 유지하며 정렬·이름 토글·출석 유형 필터와 토큰 일괄 관리에 필요한 동작만 추가한다.

FORM: 자체 후보 6, 도서관 무인 확인·발급 시스템. seed 660a9048. 후보: 강의 시간표, 답안지, 학적부, 강의실 안내판, 캠퍼스 키오스크, 도서관 확인기, 교통 검표. 사용자 지정의 차분한 현장 작업 우선순위로 결정. 외부 후보는 작업 적합성과 명료성에서 선택하지 않았다. 데이터 아트에서 정렬 규율, 행사 목록에서 명단 밀도, 교통 지도에서 상태 구별, 카세트 목록에서 정렬된 부가 정보, 시간표에서 고정 크기, 사전에서 명확한 구획을 기준으로 삼는다. 외형을 차용하지 않는다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 완료 기록
