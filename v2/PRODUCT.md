# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

특강 현장에서 휴대폰으로 출석하는 학생, 노트북으로 현황을 확인하고 예외를 처리하는 운영자.

## Product Purpose

p0as는 현장에서 받은 6자리 일회용 토큰과 학번·이름으로 일회성 강의 출석을 처리한다. 사용자는 출석·결과 조회·관리자 기능을 갖춘 v2 전체 구현과 현장에서 빨리 읽고 입력하는 차분한 화면을 요청했다.

## Stack

기존 React/Vite 프런트엔드의 기술을 유지하고, 사용자 지정 대상인 Cloudflare Pages + Pages Functions + D1으로 백엔드를 교체한다. v1은 보존하고 v2를 같은 저장소의 독립 앱으로 만든다.

## Operating Context

학생은 현장 토큰을 종이로 배부받아 입력한다. 운영자는 시작 전·진행 중·종료 상태를 관리하고 출석 및 토큰 현황, 최근 활동을 확인한다. 관리자 수동·과제 출석 승인, 잠금 해제, CSV 내보내기를 유지한다.

## Capabilities and Constraints

DB는 서버에서만 접근한다. 브라우저 공유 비밀키를 보안 경계로 사용하지 않는다. 학생에게 토큰 목록을 제공하지 않는다. 관리자는 암호화 보관된 토큰 전체 번호를 조회하고 선택 삭제·일괄 초기화·삭제할 수 있다. 토큰 관리 시 학생의 출결 기록은 유지한다. 이름은 DB에 원문과 검증값을 저장하며, 관리자 명단에서 마스킹 표시를 토글한다. 출석 유형 필터와 학번·처리 시각 정렬을 지원한다. 관리자 인증은 Cloudflare Access와 서버 검증을 사용한다. 행사명만 설정하며 학기는 사용하지 않는다.

학생 페이지는 모바일 우선이며 PC에서도 최대 440px의 한 열이다. 환경/가상 데이터 배지, 상태 배지, 푸터와 부가 캡션을 표시하지 않는다. 실제 개발 데이터는 가상 데이터만 사용한다.

등록과 조회에는 개인정보 동의 체크가 필요하다. 처리 주체는 세종대학교 K-MOOC "코딩과스토리텔링" 과목 담당 연구실이고, 보유·이용 기간 문구는 "성적 산출 및 학기 종료 시 파기"다. 미동의 시 페이지를 통한 출결 등록·조회 등을 사용할 수 없고 현장에서 조교에게 수기 출석을 요청해야 한다. 사용자는 동의 시각이나 동의문 버전을 저장하지 않도록 명시했다.

## Brand Commitments

이름 p0as. 기존 화면의 시각 언어는 이어받지 않는다. 한국어로 명확하고 차분하게 안내한다.

## Evidence on Hand

v1/README.md와 v1/src/App.jsx에 기능 구현이 있다. 실제 명단·기존 비밀키·운영 DB는 v2의 샘플이나 테스트에 사용하지 않는다.

## Product Principles

- 출석 성공 여부와 다음 행동을 즉시 이해할 수 있다.
- 보안 판단과 권한은 서버가 수행한다.
- 운영자는 예외를 처리하고 변경 기록을 확인할 수 있다.
- 모바일 학생 흐름과 넓은 관리자 작업 공간을 각각 지원한다.
