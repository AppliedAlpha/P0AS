# Pretendard Variable 1.3.9

Source: [official Pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable).

The 92 WOFF2 files are unmodified official variable dynamic subsets. `src/fonts.css` retains the official Unicode ranges and uses same-origin asset paths. Browsers request only the subsets needed by visible text; no font CDN is contacted at runtime.
